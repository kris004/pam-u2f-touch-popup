# Security Policy

## Supported versions

Security fixes are developed on `main` and included in the next stable
release. The latest stable release and the current `main` branch are supported;
older releases are not maintained.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue or pull
request. Use GitHub's [private vulnerability reporting form][private-report]
instead.

Include, where applicable:

- the affected version or commit;
- the operating system and build configuration;
- steps or a minimal reproducer;
- the expected and observed behavior; and
- your assessment of impact and realistic attacker requirements.

Reports will be investigated privately. Disclosure timing and any advisory or
release will be coordinated after the issue and remediation are understood.

For defects without security impact, use the public
[issue tracker](https://github.com/kris004/pam-u2f-touch-popup/issues).

[private-report]: https://github.com/kris004/pam-u2f-touch-popup/security/advisories/new
